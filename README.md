## 📖 Sobre o Projeto
O **Reboque Cajá RMV 24h** é um site institucional (Landing Page) projetado especificamente para converter visitantes em clientes. Construído com foco absoluto em velocidade de carregamento, responsividade e experiência do usuário (Mobile-First), ele atende à necessidade urgente de motoristas que precisam de socorro imediato nas estradas e cidades da Região Metropolitana de Recife (Igarassu, Abreu e Lima, Paulista, Goiana, etc.).

## 🚀 Principais Features (Destaques)

*   📱 **Design Mobile-First:** Desenvolvido pensando na realidade do cliente que está na rua com o celular na mão. Alvos de toque acessíveis (mínimo de 44px, respeitando a Lei de Fitts).
*   ⚡ **Performance Sênior:** Utilização do formato de imagem de última geração (`.webp`) garantindo economia de até 70% de banda e carregamento ultra rápido no 3G/4G.
*   💬 **Copys Focadas em Conversão:** Botões de WhatsApp (flutuantes e inline) com mensagens pré-programadas e persuasivas para facilitar o orçamento rápido (Pane, Colisão, Agendamento).
*   🍔 **Menu Gaveta (Drawer):** UX aprimorada com um menu hambúrguer que desliza intuitivamente pelo lado correto, com fundo escurecido (overlay) bloqueando scroll do body.
*   💎 **Estética Premium (UI):** Efeitos de *Glassmorphism* (vidro fosco translúcido) no header, *box-shadows* suaves, animações bezier de entrada (reveal no scroll) e tipografia moderna (Plus Jakarta Sans).

## 🛠️ Tecnologias Utilizadas

*   **HTML5** Semântico
*   **CSS3** (Variáveis, Flexbox, Grid, Animações, Media Queries)
*   **JavaScript (Vanilla)** para controle do DOM, Mobile Menu e Scroll Reveal.
*   **FontAwesome** para os ícones vetoriais.

## ⚙️ Funcionalidades Inteligentes

*   **App Bar Mobile:** Barra inferior fixa exclusiva para celular com acesso de 1 clique ao Telefone e WhatsApp ("SOCORRO 24H").
*   **WhatsApp Inteligente:** Ocultação condicional. Aparece como botão flutuante pulsante em Telas Grandes (Desktop/Tablet) e usa a App Bar em Telas Pequenas.
*   **Animações sob Demanda:** Botões com efeito *Pulse* (pulso de atenção) e elementos que surgem (reveal) apenas quando o usuário rola a tela.

## 💻 Como Rodar o Projeto

Este projeto não requer nenhum servidor complexo ou build de dependências.

1.  Faça o clone ou o download dos arquivos.
2.  Abra o arquivo `index.html` em qualquer navegador web.
3.  **Para hospedar:** Basta arrastar os arquivos para o GitHub Pages, Vercel, Netlify, Hostinger ou qualquer servidor estático.
